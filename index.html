mail-relay

Personal mail relay tool / 개인용 메일 중계 도구

mail-relay는 개인이 소유한 업무용 메일함(POP3)의 새 메일을 같은 사용자의 Gmail 계정으로 옮겨 주는 개인용 도구입니다. 공개 서비스가 아니며, 운영자 본인의 계정에만 사용됩니다.

mail-relay is a personal tool that copies new messages from the owner's own POP3 mailboxes into the owner's own Gmail account. It is not a public service and is used only for the operator's own accounts.
